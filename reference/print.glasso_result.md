# Print a graphical-lasso fit

Print a graphical-lasso fit

## Usage

``` r
# S3 method for class 'glasso_result'
print(x, digits = 3, ...)
```

## Arguments

- x:

  A `glasso_result` from
  [`glasso_fit()`](https://pak.dynasite.org/idiographic/reference/glasso_fit.md).

- digits:

  Number of digits used for the printed matrices.

- ...:

  Ignored.

## Value

`x`, invisibly.
