# Model diagnostics

Model diagnostics

## Usage

``` r
diagnostics(x, model = NULL, scope = NULL, subject = NULL, n = NULL, ...)
```

## Arguments

- x:

  An idiographic fit.

- model, scope, subject:

  Optional filters.

- n:

  Optional number of rows.

- ...:

  Ignored.

## Value

A tidy row-level diagnostic table.
